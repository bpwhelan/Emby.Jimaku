Jimakufin now supports Jellyfin 10.11 alongside Emby 4.8.

- Packages each server's plugin as one DLL, with no separate shared library to install.
- Registers Jimakufin in Jellyfin's subtitle downloader list and enables subtitle searches.
- Fixes mapping failures caused by comma-separated IDs in unrelated Anime-IDs records.
- Applies TVDB episode offsets when matching split anime seasons.
- Adds startup and search diagnostics without logging API keys.

For Jellyfin, add this plugin repository:
https://github.com/bpwhelan/Jimakufin/releases/latest/download/manifest.json

After installing, restart the server, enter your Jimaku API key, and enable Jimakufin and Japanese subtitles in your TV library settings. Matching requires a TVDB ID on the parent series.

When upgrading from a test build, stop the server and move the old plugin DLLs/folders and Jimaku.Shared.dll out of its plugin directory before installing. Keep your configuration XML files. The included Emby plugin remains version 1.0.2; the Jellyfin plugin is version 1.0.4.
